## Overview

The Haldankar Method Research Laboratory investigates the structural gap between high-frequency financial data and the human or machine cognitive systems that interpret it. The laboratory deconstructs how perceptual distortion, biological working memory bottlenecks, and unverified AI default assumptions create compounding institutional margin leakage.

---

## Core Research Programs

1. **Actual Profit Monograph (Human Cognitive Architecture)**
   - Analysis of the 4-chunk biological bottleneck in financial interpretation.
   - Perceptual distortion in charting, isometric transformations, and the *White Paper Test*.
2. **Decision Context Model (Machine Contextual Architecture)**
   - Upstream machine contextual governance and eliminating the silent assumption trap in institutional LLM deployments.
   - Controlled experiments and epistemic boundary enforcement (SR 26-2 regulatory alignment).
3. **Human Information Literacy (HIL)**
   - CIRF methodology and frameworks for evaluating institutional information synthesis.

## Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/haldankarmethod/the_haldankar_method_research_laboratory.git
   cd the_haldankar_method_research_laboratory
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   ```

3. **Install dependencies & run migrations:**
   ```bash
   python manage.py migrate
   ```

4. **Launch the development server:**
   ```bash
   python manage.py runserver
   ```
   Navigate to `http://127.0.0.1:8000/`.
